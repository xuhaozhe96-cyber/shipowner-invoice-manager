# Shipowner Invoice Manager

一个用于整理船东账单的程序。它可以上传 PDF、提取文字和常见字段、人工校正、按同一条船和不同船东汇总全部账单，并为 COSCO 生成专用索账邮件。仓库同时保留本地 Flask 版和 `online-site/` 私有在线版。

## 私有在线版

在线版位于 `online-site/`，使用 Sites 私有登录、D1 在线数据库和 R2 私有文件存储。在 Windows 或 Mac 上登录获授权的同一 ChatGPT 账号即可使用；源码可从私有 GitHub 仓库继续修改。

```bash
cd online-site
pnpm install
pnpm dev
```

在线版构建与测试：`pnpm test`。详细说明见 `online-site/README.md`。

## 当前功能

- 一次上传一份或多份 PDF（单次总计不超过 20 MB）
- 相同账单号只保留一条记录；再次上传时自动跳过重复文件，人工修改账单号时也会检查
- 使用 `pypdf` 提取文本，并通过可解释的规则识别：
  - 船名、航次、ETA
  - 账单号、船东、邮箱
  - 卸货港、集装箱号、箱型、提单号、金额、币种和费用明细
- 在原始提取文本旁人工核对和修改
- 保存人工校正后，本地记住该类 PDF 的版式和已确认字段；下次导入相似账单时自动优先采用学习结果，并显示来源和版式相似度
- 使用本地 SQLite 自动保存记录
- 按船舶汇总全部已录入账单，并为整条船统一维护 ETA
- 当前船舶按 ETA 从早到晚排列；完成后可移入历史记录，并可随时恢复
- 在船舶汇总内按“船东 + 邮箱”拆分，每个船东只看到自己的账单和箱号
- 按船东和集装箱汇总账单数量、B/L、箱型和金额
- 船舶汇总中的集装箱号和账单号可以直接点击，返回与新导入 PDF 相同的完整校正页面
- 每个集装箱可单独标记“已 Release / 未 Release”，并显示船东 Release 完成数量
- 可按船东一键设置本船所有集装箱的 Last Free Day 和计划提柜日期，也可逐柜单独设置；系统自动计算需要延长的天数
- 只把需要延期的集装箱整理进 Last Free Day 延期邮件，生成可直接复制到 Outlook 的格式化正文
- 船东返回延期账单后，可在对应船东卡片导入一份或多份 PDF，重新进入人工审核；确认后作为“延期账单”计入船东合计和后续付款流程
- 只有 COSCO 增加“索要账单”步骤：默认发给 `Releases@coscoshipping.co.uk`，生成 Release 主题和 Vessel / ETA / BL / Container 格式化表格；其他船东不显示索账按钮
- 按“船舶 + 船东”保存付款截图，一次可上传或从剪贴板粘贴一张或多张，并记录付款日期
- 付款截图是可选凭证；即使没有截图，也可生成 COSCO 付款后 Release 邮件。模板包含付款、账单、船舶、B/L 和箱号明细，不包含外部邮件警告文字
- 导出全部记录或单个船舶分组为 `.xlsx`

> MVP 不会自动发送邮件。这样可以在 PDF 识别和收件人信息被人工确认前，避免误发。

## 环境要求

- Windows、macOS 或 Linux
- Python 3.10 或更高版本

## 运行方法

Windows 用户也可以直接双击 `start_windows.bat`。它会首次创建本地环境、安装所需组件、启动程序并自动打开浏览器。使用期间请保持启动窗口开启；关闭该窗口后，本地页面也会停止。

Mac 用户可使用 `start_mac.command`。第一次使用请按照 `MAC迁移说明.txt` 为启动文件添加运行权限；Mac 版默认打开 <http://127.0.0.1:5050>，以避开 AirPlay 可能占用的 5000 端口。

在本项目目录打开终端，然后执行：

### Windows PowerShell

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

### macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```

浏览器打开：<http://127.0.0.1:5000>

## 数据存放位置

- 数据库：`data/shipowner_invoices.db`
- 上传的 PDF：`data/uploads/`
- 付款截图：`data/payment_proofs/`

上述路径是本地 Flask 版的数据。备份项目的 `data` 文件夹即可备份本地记录和原始 PDF；在线版则分别保存在 Sites D1 和 R2 中，账单数据不会提交到 GitHub。

## 使用流程

1. 点击“上传 PDF”，选择船东账单。
2. 系统提取文字并预填可能识别到的字段。
3. 对照右侧原文或原始 PDF 修改字段，然后保存。
4. 保存后系统会记住这类账单的已确认字段位置；下一张相似版式会自动套用，并提示哪些字段来自校正记忆。
5. 首页会自动把同一条船的所有账单汇总在一起。
6. 进入船舶汇总页，统一设置 ETA，并查看整船账单和金额合计；点集装箱号或账单号可随时回去修改。
7. 系统按不同船东和集装箱拆分记录；只有 COSCO 显示“生成索账邮件”。
8. 如有付款截图，可在对应船东卡片上传或点击粘贴区后按 `Ctrl+V`，并填写付款日期。
9. 在船东卡片设置 Last Free Day 和计划提柜日期；系统自动显示“无需延长”或“延长 N 天”。
10. 有柜需要延期时，生成延期邮件并复制到 Outlook；收到延期账单后，从同一卡片导入并重新审核。
11. COSCO 可直接生成付款后的 Release 邮件；复制主题和格式化正文到 Outlook。
12. 收到 Release 后，在对应集装箱旁切换为“已 Release”。
13. 该船工作完成后点击“结束”，记录进入历史；需要再次处理时可点击“恢复”。

## 已知限制

- 扫描图片型 PDF 没有文本层，当前版本不会 OCR；程序会提示手工填写。
- 不同船东的账单版式差异很大，规则识别只是预填助手，仍需人工确认。
- 校正记忆只在版式足够相似时启用；它不会训练云端模型，学习记录保存在本地 SQLite 或私有在线 D1 数据库中。
- 当前每个 PDF 对应一条记录；一份 PDF 内包含多张独立账单时需要手工拆分。
- 邮件草稿只保存在系统中，不连接 Gmail 或 Outlook。
- 本地 Flask 版没有登录；在线版由 Sites 私有访问控制保护。
