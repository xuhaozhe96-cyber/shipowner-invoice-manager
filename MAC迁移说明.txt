Shipowner Invoice Manager — Mac 迁移说明
========================================

这个文件夹已经包含当前电脑上的：
- 账单数据库和校正学习记录
- 已上传的 PDF
- 付款截图
- 程序和邮件模板

一、把压缩包传到 Mac
可使用 AirDrop、U 盘、OneDrive 或其他文件传输方式。传到 Mac 后解压缩，建议把整个文件夹放到“文稿”目录。

二、安装 Python
如果 Mac 尚未安装 Python 3.10 或更高版本，请访问：
https://www.python.org/downloads/macos/

三、第一次启动
1. 打开“终端”（Terminal）。
2. 输入：chmod +x （注意 x 后面有一个空格）。
3. 把文件夹里的 start_mac.command 拖进终端窗口，然后按回车。
4. 双击 start_mac.command。

第一次启动会从网络安装所需组件，完成后浏览器会自动打开：
http://127.0.0.1:5050

以后直接双击 start_mac.command 即可。

如果 Mac 提示无法验证开发者：
请右键点击 start_mac.command，选择“打开”，再确认一次“打开”。

重要说明
--------
- 程序和数据仍然完全保存在 Mac 本机，不会自动上传到云端。
- 这个迁移包是制作时的数据快照。迁移后，Windows 和 Mac 上的新修改不会自动互相同步。
- 请不要只复制数据库文件；备份或再次迁移时，应复制整个 data 文件夹。
- 使用程序时不要关闭启动程序的终端窗口。
